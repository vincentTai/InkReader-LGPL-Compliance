# InkReader Support

For support, open an issue at
<https://github.com/vincentTai/InkReader-LGPL-Compliance/issues>.

Please include the iOS version, device model, source format, and the exact
on-screen error. Do not upload copyrighted or protected books. If a file is
needed to reproduce an import issue, provide only a small unprotected sample
that you are allowed to share.

InkReader supports EPUB, PDF, TXT, HTML/XHTML, Markdown, FB2/FB2.ZIP, CBZ,
CBR, and unprotected MOBI/AZW/AZW3/PRC. Protected ebooks cannot be opened.
